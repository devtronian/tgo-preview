## แก้ไขเนื้อหา
- **ข้อความ**: ทุกข้อความมี 2 ภาษาอยู่คู่กัน `<span data-l="th">…</span><span data-l="en">…</span>`
- **ตำแหน่งงาน**: แก้ที่ `assets/js/jobs.js` ไฟล์เดียว (เพิ่ม/ลบรายการได้เลย)
- **เมนู, footer, เบอร์โทร, อีเมล**: `assets/js/layout.js` (ตัวแปร `CO` และ `NAV`)
- **สี/ฟอนต์**: ตัวแปรใน `:root` ของ `assets/css/style.css`

## ⚠️ ต้องเปลี่ยนก่อนเปิดใช้งานจริง (ข้อมูลตัวอย่าง)
1. **รีวิว 3 รายการ** ใน `index.html` (คุณนิภา, คุณอรุณี, ผู้จัดการสปา) — เป็นข้อความตัวอย่าง ต้องแทนด้วยรีวิวจริงที่ได้รับอนุญาต
2. **ทีมผู้บริหาร** ใน `about.html` — ชื่อ "ชื่อ–นามสกุล" และรูป silhouette
3. **ตำแหน่งงาน** ใน `assets/js/jobs.js` — เป็นตัวอย่างตามสายงาน/ประเทศที่ให้มา
4. **ข้อความที่ควรยืนยัน**: ระยะเวลา "2–4 เดือน" (FAQ), "ออกใบเสร็จในนามบริษัททุกครั้ง", วิสัยทัศน์/พันธกิจ (เขียนเติมให้)
5. **แผนที่**: ตอนนี้ค้นหาจากที่อยู่ — แนะนำให้แทน `src` ของ iframe ใน `contact.html` ด้วยลิงก์ฝังจาก Google Maps (แชร์ → ฝังแผนที่) ของหมุดจริง
6. **ชื่ออังกฤษ**: เอกสารใช้ "TG Oversea Solutions" แต่โลโก้เขียน "TG Overseas Solutions" — ยืนยันชื่อที่จดทะเบียน
