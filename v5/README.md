## แนวคิด
**หน้าต่างเครื่องบิน** คือสัญลักษณ์ของการไปทำงานต่างประเทศ จึงเป็นลูกเล่นหลักของทั้งเว็บ
- **Hero**: หน้าต่างเครื่องบินที่ "ม่านบังแดด" เลื่อนปิด-เปิดเพื่อเปลี่ยนวิวเมืองปลายทาง พร้อมการ์ดเส้นทางบิน BKK → DXB ที่มีเครื่องบินวิ่งตามเส้น, นาฬิกาเวลากรุงเทพฯ และจำนวนตำแหน่งงาน
- **หน้าต่างเปิดสู่โลก**: เลื่อนจอลงแล้วหน้าต่างค่อย ๆ ขยายเต็มจอเป็นภาพปีกเครื่องบินเหนือเมฆ พร้อมตัวเลขที่นับขึ้น
- **Bento "ทำไมต้อง TG"**: แผนที่โลกแบบจุดที่เส้นทางบินจากกรุงเทพฯ วาดตัวเองออกไปยังทุกประเทศ, การ์ดใบอนุญาตเอียงตามเมาส์, ใบเสร็จที่รายการค่อย ๆ ขึ้น, คำทักทายหลายภาษา, แชตกับเจ้าหน้าที่
- **สายงาน**: แผงภาพที่ขยายเมื่อชี้/แตะ  **ปลายทาง**: การ์ดภาพแนวตั้งลากเลื่อนได้ มี parallax
- **ขั้นตอน**: การ์ดซ้อนกันขณะเลื่อน (sticky stack)  **ตำแหน่งงาน**: กรองแล้วการ์ดเลื่อนเข้าที่อย่างนุ่มนวล (FLIP)
- หัวข้อทุกอันขึ้นทีละวลีแบบ mask reveal, เปลี่ยนหน้าแบบ View Transitions, ปุ่มแม่เหล็ก, spotlight ตามเมาส์, แถบความคืบหน้าการอ่าน, header ซ่อนเมื่อเลื่อนลง

## SEO และความเร็ว
- URL แยกภาษา `/` และ `/en/` + hreflang, canonical, Open Graph พร้อมภาพแชร์ 2 ภาษา
- เนื้อหา เมนู และตำแหน่งงานอยู่ใน HTML ตรง ๆ (ไม่ต้องรอ JavaScript) ทุกหน้ามี H1 เดียว
- Structured data: EmploymentAgency (เลขใบอนุญาต ที่อยู่ เบอร์โทร), WebSite, BreadcrumbList, FAQPage, Service, ItemList และรองรับ JobPosting (Google for Jobs)
- `sitemap.xml`, `robots.txt`, `llms.txt` (สรุปให้ AI search), `site.webmanifest`, `404.html`
- ไม่มีไลบรารีภายนอก: CSS ไฟล์เดียว + JS ไฟล์เดียว รูปทั้งหมดเป็น WebP 2 ขนาด (srcset) โหลดแบบ lazy, preload ภาพแรก, prerender หน้าถัดไปด้วย Speculation Rules
- แอนิเมชันใช้ transform/opacity เป็นหลัก ทำงานที่ 60fps; ถ้า JS โหลดไม่ได้ เนื้อหาจะแสดงครบภายใน 2.5 วินาที

## แก้เนื้อหา
แก้ไฟล์ใน `_build/` แล้วรัน `node _build/build.mjs` (ในโฟลเดอร์ `v5`, ต้องมี Node.js 18+)

| ต้องการแก้ | ไฟล์ |
|---|---|
| โดเมน, เบอร์โทร, อีเมล, ที่อยู่, เมนู, ธีม | `_build/site.mjs` |
| ตำแหน่งงาน | `_build/jobs.mjs` |
| ข้อความแต่ละหน้า (`c.L("ไทย", "English")`) | `_build/pages.mjs` |
| สายงาน, ปลายทาง, ขั้นตอน, FAQ | `_build/content.mjs` |
| header / footer / meta / Schema | `_build/layout.mjs` |

### เปลี่ยนรูป
วาง JPG ใน `_build/photos-src/` แล้วรันในโฟลเดอร์ `v5` (ต้องมี Python + Pillow):
```
python -c "from PIL import Image;import glob,os,json;m={}
for f in glob.glob('_build/photos-src/*.jpg'):
 n=os.path.splitext(os.path.basename(f))[0];im=Image.open(f).convert('RGB');m[n]={'w':im.width,'h':im.height,'c':'#%02x%02x%02x'%im.resize((1,1)).getpixel((0,0))}
 for w in (640,1280):
  r=im.copy();r.thumbnail((w,w*3));r.save(f'assets/img/{n}-{w}.webp',quality=72,method=6)
json.dump(m,open('_build/img-meta.json','w'))"
node _build/build.mjs
```

## ⚠️ ก่อนเปิดใช้จริง
1. ใส่โดเมนจริงที่ `SITE_URL` ใน `_build/site.mjs` แล้ว build ใหม่ และอัปโหลดเนื้อหาใน `v5/` ไว้ที่ root ของโดเมน (ไม่ต้องอัปโหลด `_build/`)
2. **รูปภาพเป็นภาพแนวคิดจาก Unsplash** (ดู `ASSETS.md`) — แทนด้วยรูปจริงของบริษัท
3. **รีวิว 3 รายการในหน้าแรกเป็นตัวอย่าง** — แทนด้วยรีวิวจริงที่ได้รับอนุญาต (ไม่ได้ใส่ใน Schema)
4. **ตำแหน่งงานเป็นตัวอย่าง** — ใส่งานจริงแล้วค่อยตั้ง `EMIT_JOB_POSTING = true`
5. ข้อความที่เติมเพื่อความสวยงาม ควรยืนยันกับบริษัท: เวลาบินโดยประมาณ, ข้อความแชตตัวอย่าง, "2–4 เดือน", ทีมผู้บริหาร (ใส่ชื่อจริง)
6. ภาพมัสยิดในการ์ด "โอมาน" เป็นภาพทั่วไป ไม่ใช่สถานที่ในโอมาน
