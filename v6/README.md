# TG Oversea Solutions — แบบที่ 6 "Clear Path"

เว็บไซต์บริษัทจัดหางานไปต่างประเทศ 7 หน้า (รวมหน้าโปรไฟล์บริษัทแบบหนังสือ) ไทย/อังกฤษแยก URL เน้นความน่าเชื่อถือและความชัดเจนของขั้นตอน
เปิดดู: [ภาษาไทย](index.html) · [English](en/index.html) · [เทียบทุกแบบ](../versions.html)

## แนวคิด
แบบนี้ตั้งใจให้ดูเป็น **เว็บบริษัทจัดหางาน ไม่ใช่เว็บท่องเที่ยว** จึงไม่ใช้ภาพเมือง วิว หรือเครื่องบิน
แต่ใช้ภาพคนทำงานจริง และเล่าเรื่องผ่าน "สิ่งที่ผู้สมัครอยากรู้": งานนี้ถูกกฎหมายไหม ต้องทำอะไรบ้าง จ่ายอะไรบ้าง

- **สี**: น้ำเงินกรมท่าสื่อความน่าเชื่อถือ, เหลืองอำพันแบบเสื้อสะท้อนแสงสื่อถึงงานภาคสนาม, เขียวใช้กับเครื่องหมาย "ตรวจสอบแล้ว"
- **ตัวอักษร**: Anuphan (ไทย) + Geist (อังกฤษ/ตัวเลข)
- **Hero**: การ์ดติดตามสถานะการสมัคร (ระบุว่าเป็น "ตัวอย่าง") ที่ติ๊กผ่านทีละขั้น แล้วสลับเป็นผู้สมัครคนถัดไป พร้อมภาพเปลี่ยนตามสายงาน
- **"อย่าเพิ่งเชื่อเรา ตรวจสอบเราก่อน"**: การ์ดใบอนุญาต เลขที่ถอดรหัสทีละหลัก ปุ่มคัดลอกเลข และลิงก์ไป doe.go.th
- **ตำแหน่งงาน**: รายการที่กรองตามสายงานได้ ชี้แล้วมีภาพลอยตามเมาส์
- **6 ขั้นตอน**: เลื่อนจอลงแล้วการ์ดเลื่อนไปทางขวา (เลื่อนแนวนอนขณะหน้าค้างอยู่) บนมือถือปัดซ้าย-ขวา
- **ข้อตกลงของเรา**: สิ่งที่เราทำทุกครั้ง / สิ่งที่เราไม่ทำ
- **ประเทศปลายทาง**: แยกชัดว่า "ส่งแรงงานแล้ว" หรือ "เครือข่ายพันธมิตร" พร้อมแผนที่ที่ลากเส้นจากไทย
- **โปรไฟล์บริษัท** (`profile.html`): โปรไฟล์ 15 หน้าของบริษัทเป็นหนังสือพลิกหน้าได้ (ดูหัวข้อถัดไป) หน้าเกี่ยวกับเรามีการ์ดลิงก์มาที่หน้านี้
- หัวข้อค่อย ๆ ปรากฏทีละวลี, ภาพเผยตัวเมื่อเลื่อนถึง, แถบความคืบหน้าการอ่านใต้ header, FAQ เปิด-ปิดนุ่ม ๆ, เปลี่ยนหน้าแบบ View Transitions

## โปรไฟล์บริษัท (หนังสือพลิกหน้า)
- **จอกว้าง** แสดงทีละสองหน้า ปกอยู่กลางเล่มตอนปิด / **มือถือและแท็บเล็ตแนวตั้ง** แสดงทีละหน้า
- **การพลิก**: วาดแบบกระดาษพับจริง (ไม่ใช่หมุนทั้งแผ่น) มุมกระดาษถูกดึงตามเส้นโค้ง พับตามแนวเฉียง เห็นด้านหลังของแผ่น มีแสงที่รอยพับและเงาบนหน้าที่โผล่ขึ้นมา
  - คลิกหน้าขวา/ซ้าย ปุ่มลูกศร หรือปุ่มลูกศรบนคีย์บอร์ด
  - ลากหน้า: จับครึ่งบนพับมุมบน จับครึ่งล่างพับมุมล่าง ปล่อยเกิน 30% หรือปัดเร็ว ๆ แล้วพลิกต่อจนจบ ไม่ถึงก็เด้งกลับ
  - ชี้เมาส์ที่มุมหน้า: มุมยกขึ้นเล็กน้อยตามเมาส์
- **แถบเครื่องมือ**: ดูทุกหน้า (ภาพย่อ), แถบเลื่อนเลือกหน้า, ขยายอ่าน (ภาพ 2000px เลื่อนและซูมได้), เสียงพลิกหน้า (ปิดเป็นค่าเริ่มต้น), เต็มจอ (iPhone ใช้แบบเต็มหน้าต่างแทน), ดาวน์โหลด PDF
- ลิงก์ `profile.html#page-5` เปิดหน้า 5 ได้ตรง ๆ และสลับภาษาแล้วยังอยู่หน้าเดิม
- ไม่มี JavaScript: แสดงทุกหน้าเรียงลงมาเป็นรูป / ลดการเคลื่อนไหว: เปลี่ยนหน้าทันที
- ทุกหน้ามีคำอธิบายรูป (alt) ที่บอกเนื้อหาของหน้านั้น ทั้งไทยและอังกฤษ สำหรับโปรแกรมอ่านหน้าจอและ SEO

### ภาพหน้าโปรไฟล์
ต้นฉบับอยู่ที่ `../docs/รูปภาพบริษัท` (ไม่อยู่ใน Git เพราะมี PSD เกือบ 900 MB เก็บสำรองไว้นอก repo)
- ลำดับและเนื้อหาของเล่มยึดตามไฟล์ PNG ที่บริษัท export ไว้ใน `โปรไฟล์รูปภาพ TG(TH)` และ `(ENG)` ทั้งหมด 15 หน้า
- หน้าที่ PSD ตรงกับ PNG ทุกส่วน (ตรวจเทียบเป็นช่อง ๆ แล้ว) สร้างภาพจาก PSD ขนาด 2480×3508 ให้ตัวหนังสือคมเวลาขยาย
- **ปก** และ **หน้า 13 "T.G. Labor Experience" ภาษาอังกฤษ** ไม่มี PSD ที่ตรงกัน (PSD ปกเป็นดีไซน์เก่า PSD หน้า 13 ยังใช้โลโก้เก่า) จึงใช้ PNG ขนาด 595px ซึ่งจะดูไม่คมเท่าหน้าอื่น
- ไม่ได้ใส่ PSD "Our Network & Partnership" และ "Contact us" เพราะไม่อยู่ในชุดที่ export

สร้างภาพหน้าใหม่ (ในโฟลเดอร์ `v6` ต้องมี Python + Pillow และโฟลเดอร์ `docs` อยู่ที่เดิม):
```
python _build/profile-pages.py
node _build/build.mjs
```
ได้ไฟล์ `assets/profile/{th|en}-{หน้า}-{240|640|1280|2000}.webp` (240 ใช้เป็นภาพย่อ, 2000 ใช้ตอนขยายอ่าน), `tg-company-profile-{th|en}.pdf` และ `_build/profile-meta.json`
ถ้าเพิ่ม ลบ หรือสลับหน้า ให้แก้ทั้ง `PAGES` ใน `profile-pages.py` และ `PROFILE` ใน `_build/profile.mjs` (ชื่อหน้า + alt) ให้ตรงกัน

## ปรับการแสดงผล (ปุ่มรูปจานสีมุมขวาบน)
| ธีม | โทน |
|---|---|
| สว่าง | เทาอ่อน + น้ำเงินกรมท่า + เหลืองอำพัน |
| มืด | น้ำเงินเข้มเกือบดำ + เหลืองสว่าง |

ก่อนผู้ใช้เลือก เว็บจะเป็นสว่างหรือมืดตามการตั้งค่าของเครื่อง เมื่อเลือกแล้วจะจำไว้ทุกหน้า (ค่าเดิมจากธีมที่เลิกใช้: กะกลางคืน → มืด, อื่น ๆ → สว่าง)

- **ภาพเคลื่อนไหวหน้าแรก** (แสดงเฉพาะในหน้าแรก) เลือกได้ 4 แบบ ข้อความด้านซ้ายเหมือนกันทุกแบบ เปลี่ยนเฉพาะภาพด้านขวา
  | แบบ | สิ่งที่เห็น |
  |---|---|
  | ติดตามสถานะ (แบบเดิม, ค่าเริ่มต้น) | ภาพคนทำงาน + การ์ดสถานะการสมัครที่ติ๊กผ่านทีละขั้น |
  | บอร์ดตำแหน่งงาน | การ์ดงานจริงจาก `jobs.mjs` 2 แถวเลื่อนสวนทางกันช้า ๆ ชี้เมาส์แล้วหยุด กดเข้าไปดูงานได้ |
  | ตรวจเอกสาร | กองเอกสาร (สัญญา ใบรับรองแพทย์ วีซ่า ใบเสร็จ) ถูกประทับ "ตรวจแล้ว" ทีละฉบับ พร้อมเช็กลิสต์ |
  | ภาพสายงาน | ภาพ 4 สายงาน ภาพที่เลือกขยายใหญ่และแสดงตำแหน่งงาน ประเทศ และจำนวนงาน หมุนเวียนอัตโนมัติ ชี้เมาส์เพื่อเลือกเอง |

  ค่าเริ่มต้นคือ "ติดตามสถานะ" ถ้าจะเปลี่ยนเป็นแบบอื่น ต้องแก้ 3 ที่ให้ตรงกัน: `HEROES` ใน `_build/site.mjs`, ตัวเลือก `.hv` ใน `assets/css/site.css` และ `curHero` ใน `assets/js/site.js`
- **ขนาดตัวอักษร** 3 ระดับ (ปกติ / ใหญ่ / ใหญ่มาก) สำหรับผู้สูงอายุหรือครอบครัวผู้สมัคร
- **ลดการเคลื่อนไหว** ปิดแอนิเมชันทั้งหมด (และเคารพการตั้งค่าของเครื่องอัตโนมัติ)
- ทุกค่าจำไว้ทุกหน้าทั้งสองภาษา เปลี่ยนธีมแล้วมีวงกลมกระจายจากปุ่ม

## สลับภาษา
ปุ่ม **ไทย | EN** อยู่ใน header, เมนูมือถือ และ footer กดแล้วไปหน้าเดียวกันในอีกภาษา **และอยู่ที่หัวข้อเดิม** ที่กำลังอ่าน
(รวมถึงตัวกรองงานที่เลือกไว้) แต่ละภาษามี URL ของตัวเองเพื่อ SEO

## SEO และความเร็ว
- URL แยกภาษา `/` และ `/en/` + hreflang, canonical, Open Graph พร้อมภาพแชร์ 2 ภาษา
- เนื้อหา เมนู และตำแหน่งงานอยู่ใน HTML ตรง ๆ ทุกหน้ามี H1 เดียว
- Structured data: EmploymentAgency (เลขใบอนุญาต ที่อยู่ เบอร์โทร), WebSite, BreadcrumbList, FAQPage (หน้าแรกและหน้าขั้นตอน), Service, ItemList และรองรับ JobPosting (Google for Jobs)
- `sitemap.xml`, `robots.txt`, `llms.txt` (สรุปให้ AI search), `site.webmanifest`, `404.html`
- ไม่มีไลบรารีภายนอก (หนังสือโปรไฟล์ก็เขียนเอง): CSS ไฟล์เดียว + JS ไฟล์เดียว รูปเป็น WebP 2 ขนาด (srcset) โหลดแบบ lazy, preload ภาพแรก, prerender หน้าถัดไป
- ถ้า JavaScript โหลดไม่ได้ หรือเปิดลดการเคลื่อนไหว เนื้อหาทั้งหมดยังแสดงครบ

## แก้เนื้อหา
แก้ไฟล์ใน `_build/` แล้วรัน `node _build/build.mjs` (ในโฟลเดอร์ `v6`, ต้องมี Node.js 18+)
แผนที่ประเทศปลายทางใช้จุดแผนที่จาก `../v1/assets/js/land-dots.js` ต้องมีโฟลเดอร์ `v1` อยู่ข้าง ๆ ตอน build

| ต้องการแก้ | ไฟล์ |
|---|---|
| โดเมน, เบอร์โทร, อีเมล, ที่อยู่, เมนู, ธีม | `_build/site.mjs` |
| ตำแหน่งงาน | `_build/jobs.mjs` (ภาพของแต่ละงานที่ `JOB_IMG` ใน `content.mjs`) |
| ข้อความแต่ละหน้า (`c.L("ไทย", "English")`) | `_build/pages.mjs` |
| สายงาน, ขั้นตอน, ข้อตกลง, ประเทศ, FAQ, การ์ดตัวอย่างใน hero | `_build/content.mjs` |
| header / footer / meta / Schema | `_build/layout.mjs` |
| ชื่อหน้าและคำอธิบายรูปของโปรไฟล์ | `_build/profile.mjs` |
| หนังสือโปรไฟล์ (การพลิก, แถบเครื่องมือ) | `assets/js/site.js` ส่วน "Company profile: flip book" และ `assets/css/site.css` ส่วนเดียวกัน |
| สีของแต่ละธีม | `assets/css/site.css` ส่วน `[data-theme="…"]` |

### เปลี่ยนรูป
วาง JPG ใน `_build/photos-src/` แล้วรันในโฟลเดอร์ `v6` (ต้องมี Python + Pillow):
```
python -c "from PIL import Image;import glob,os,json;m={}
for f in glob.glob('_build/photos-src/*.jpg'):
 n=os.path.splitext(os.path.basename(f))[0];im=Image.open(f).convert('RGB');m[n]={'w':im.width,'h':im.height,'c':'#%02x%02x%02x'%im.resize((1,1)).getpixel((0,0))}
 for w in (640,1280):
  r=im.copy();r.thumbnail((w,w*3));r.save(f'assets/img/{n}-{w}.webp',quality=72,method=6)
json.dump(m,open('_build/img-meta.json','w'))"
node _build/build.mjs
```

## ⚠️ ก่อนเปิดใช้จริง
1. ใส่โดเมนจริงที่ `SITE_URL` ใน `_build/site.mjs` แล้ว build ใหม่ และอัปโหลดเนื้อหาใน `v6/` ไว้ที่ root ของโดเมน (ไม่ต้องอัปโหลด `_build/`)
2. **รูปภาพเป็นภาพแนวคิดจาก Unsplash** (ดู `ASSETS.md`) แทนด้วยรูปจริงของบริษัท
3. **ตำแหน่งงานเป็นตัวอย่าง** ใส่งานจริงแล้วค่อยตั้ง `EMIT_JOB_POSTING = true`
4. **การ์ดติดตามสถานะใน hero เป็นภาพประกอบ** (ติดป้าย "ตัวอย่าง") ไม่ใช่ข้อมูลผู้สมัครจริง
5. **ข้อความที่ควรให้บริษัทยืนยัน**: รายการ "สิ่งที่เราทำทุกครั้ง / สิ่งที่เราไม่ทำ", "เลขใบอนุญาตอยู่บนสัญญาและใบเสร็จทุกฉบับ", "สัญญาจ้างฉบับภาษาไทย", รายการค่าใช้จ่ายในหน้าขั้นตอน, "2–4 เดือน", "5+ ปี", สถานะ "ส่งแรงงานแล้ว / เครือข่ายพันธมิตร" ของแต่ละประเทศ
6. ทีมผู้บริหารในหน้าเกี่ยวกับเรา ใส่ชื่อจริงและรูปถ่าย (มีชื่อ ตำแหน่ง และรูปจริงอยู่ในหน้า 4–5 ของโปรไฟล์แล้ว)
7. **ฟอร์มติดต่อยังเป็น mailto** คือเปิดแอปอีเมลของผู้ใช้ และผู้ใช้ต้องกดส่งเอง ข้อมูลจึงอาจไม่ถึงบริษัท ก่อนเปิดใช้จริงควรเชื่อม Google Sheets + Apps Script (บันทึกลงชีตและส่งเข้า Gmail) หรือ Web3Forms และเพิ่มหน้าประกาศความเป็นส่วนตัวตาม PDPA
8. **โปรไฟล์บริษัท**: ขอไฟล์ปกความละเอียดสูงจากผู้ออกแบบ และให้บริษัทยืนยันชื่อที่ใช้ ("TG Overseas" ในโปรไฟล์ / "TG Oversea" ในเว็บและอีเมล) กับการสะกดชื่อกรรมการภาษาอังกฤษ ("Kodunya" / "Kodanya" ไม่ตรงกันระหว่างหน้า)
