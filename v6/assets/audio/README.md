# Book sounds

Kenney Vleugels, RPG sounds, CC0. Original license: `Kenney-license.txt`.
Source: https://opengameart.org/content/50-rpg-sound-effects
Archive: https://opengameart.org/sites/default/files/RPGsounds_Kenney.zip

`bookFlip1.mp3`, `bookFlip2.mp3`, `bookFlip3.mp3`, and `bookOpen.mp3`
are mono MP3 transcodes of the corresponding original OGG files.
Served locally; no third-party requests are made during playback.
